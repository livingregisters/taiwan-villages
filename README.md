# 台灣退休宅追蹤表 · Taiwan Retirement Villages Tracker

A quarterly register of retirement villages (養生村, 退休宅) in Taiwan: costs, entry conditions, supply and price history, with each figure tagged by source and verification status.

- Live page: https://livingregisters.github.io/taiwan-villages/
- Data: `retirement-villages.md` (the page reads this file when it loads)
- Updates: checked against sources each quarter; every change is visible in this repository's history.

Information only. Figures come from public sources and may be out of date; confirm with the operator before relying on them.
